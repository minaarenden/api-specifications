# API-specifikationer från Mina ärenden
Detta repository innehåller API-specifikationer från Mina ärenden, som arbetar med att tillgängliggöra ärendeåterkoppling från det offentliga.

Vi vill uppmärksamma dig på att det finns specifikationer till både producenter och konsumenter och att det är viktigt att skilja på dessa. Läs nedan om du är osäker på vilken roll du har.

## Producent eller konsument?
Producenter är offentliga aktörer, kommuner, regioner eller statliga myndigheter som handlägger ärenden och vill återkoppla hur det går i ärendena till dem det berör, det vill säga privatpersoner eller företag.

Konsumenter är offentliga aktörer eller programvaruföretag som tillhanda håller en tjänst som visar upp ärendeåterkoppling för dessa privatpersoner eller företag.

Många offentliga aktörer kommer förmodligen att vara både producenter och konsumenter.

## Gör så här
Om du är producent och vill ansluta till Mina ärendens vidareförmedlingstjänst kan du följa specifikationerna i detta repository. 

Om du istället är konsument kan du också hitta mer information här: [Skatteverkets utvecklarportal](https://www7.skatteverket.se/portal/apier-och-oppna-data/utvecklarportalen/api/mina-arenden-kundhandelser/1.0.0/%C3%96versikt)

## Mina ärenden - en del av ENA
Mina ärenden är ett initiativ inom ENA – Sveriges digitala infrastruktur. Vårt arbete syftar till att tillgängliggöra ärendeåterkoppling från det offentliga till privatpersoner och företag. För att uppnå det har vi tagit fram en nationell standard för ärendeåterkoppling. Vi tillhandahåller även en vidareförmedlingstjänst som myndigheter, kommuner och regioner kan ansluta till som producenter för att leverera ärendeåterkoppling i form av kundhändelser. Till vidareförmedlingstjänsten kan även offentliga aktörer eller programvaruföretag ansluta för att hämta ärendeåterkoppling och visa upp för sina kunder.

Läs mer om Mina ärenden på [Digg.se/minaarenden](https://digg.se/minaarenden)
